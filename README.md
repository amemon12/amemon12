# Computer Science @ UW

I'm a computer science student at UW interested in backend engineering,
distributed systems, and building useful applications with AI.

My projects explore distributed model inference, voice-driven interfaces,
and automated research workflows. I focus on understanding how systems
behave, testing failure cases, and documenting their tradeoffs.

I'm currently seeking software engineering internships.

## Selected projects

### [Hypercompute](https://github.com/amemon12/Hypercompute)
A distributed inference prototype that connects heterogeneous computers
to run models larger than a single machine can hold.

Explore the implementation, dashboard, and hardware benchmarks—including
the conditions where distributing a model helps and where it adds overhead.

### [ShelfAware](https://github.com/amemon12/shelfaware)
A voice-driven shopping assistant for iPhone and Meta glasses that combines
visual product identification, cited search, and conversational comparisons.

The project spans a SwiftUI app, FastAPI backend, and React companion,
with tests covering conversation state and provider failures.

### [BTC AutoResearch](https://github.com/amemon12/btc-autoresearch)
A local research application for evaluating Bitcoin trading strategies,
tracking experiments, and paper trading.

It combines a Python CLI, SQLite persistence, a backtesting pipeline,
and a Streamlit dashboard. It is an experimental research tool;
execution is limited to paper trading.
